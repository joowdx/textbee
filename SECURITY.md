# Security Policy

## Reporting a Vulnerability

Please don't open a public issue for a vulnerability in textbeeqtt. Report it privately through GitHub's [private vulnerability reporting](https://github.com/joowdx/textbee/security/advisories/new) for this repository instead.

Issues that also affect upstream textbee should be reported to [vernu/textbee](https://github.com/vernu/textbee) as well.
